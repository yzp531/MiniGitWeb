# MiniGitWeb

基于 Web 的 Git 仓库管理工具，提供简洁直观的界面来管理您的 Git 仓库。

## 功能特性

### 📂 仓库管理
- **仓库挂载**: 输入仓库路径快速挂载
- **快捷切换**: 已挂载的仓库自动保存，一键切换
- **路径历史**: 自动记录输入过的路径，方便选择

### 🔧 Git 操作
- **Status**: 查看仓库状态，显示修改/暂存/未跟踪文件
- **Add**: 选择文件加入暂存区，支持全选/反选
- **Push**: 推送代码到远程，支持自定义 commit 信息
- **Pull**: 拉取远程最新代码
- **Stash**: 暂存工作区修改，支持恢复和删除
- **Branch**: 分支管理，支持创建/切换/删除分支

### 🎨 界面特性
- **响应式设计**: 完美适配桌面端和移动端
- **主题切换**: 支持深色/浅色主题
- **操作历史**: 记录所有操作，支持回溯
- **控制台输出**: 实时显示 Git 命令执行结果
- **全屏模式**: 控制台支持全屏显示，便于查看大量输出

### 📱 移动端优化
- **折叠面板**: 仓库目录和操作按钮支持折叠
- **触摸友好**: 按钮大小适合移动端点击

## 快速开始

### 前置要求
- Node.js 14+
- npm 或 yarn

### 安装

```bash
# 克隆仓库
git clone https://github.com/yzp531/MiniGitWeb.git
cd MiniGitWeb

# 安装依赖
cd server
npm install
```

### 运行

```bash
# 启动服务器
node index.js
```

访问 http://localhost:3000 即可使用

## 使用说明

1. **登录**: 输入用户名和密码登录系统
2. **挂载仓库**: 在"仓库目录"输入框中输入 Git 仓库的绝对路径，点击"挂载"
3. **执行操作**: 挂载成功后，点击相应的操作按钮（Status、Add、Push 等）
4. **切换仓库**: 点击快捷路径中的仓库名称即可快速切换
